Eight projects, eight lessons

What CitCat is for

Every project below is a real, finished .citcat file — not a mockup. Each one teaches a different part of the tool: animation, interactivity, data binding, audio-synced video. Read top to bottom for the full tour, or jump straight to whatever interests you.

Landing Showreel

The reel already on the homepage: animated GIF, video, SVG and bound-looking text compositing live in one twenty-second pass. Start here — it's the fastest answer to "what does CitCat actually do."

Demo Showcase

CitCat's own built-in tour: gradients and keyframe motion, a product-card layout, and a hidden click interaction with a wait point. The broadest single project in the lineup.

Guest Reel — built by Mara

Guest piece

A designer's own take on the same pitch, made the one time Mirjam handed a non-engineer the tool: ambient audio, an SVG mark, trimmed video, a hotspot that's "listening." Proof the tool holds up outside the team that built it.

Company Intro

Click-to-advance slides with staggered reveals and crossfade/slide transitions between them — an animated presentation in place of a slide deck.

Safety Training

A three-answer quiz with its own feedback text, wait points that pause until the learner responds, and items that reveal one by one. The branching case, not just playback.

Lyric Video

Audio-synced lyric timing, trimmed video under keyframed colour filters, bezier motion paths, and burned-in subtitles — the deepest feature stack here, exported to MP4 as readily as HTML5.

Product Showcase

Exported HTML5

One template × a five-row CSV = five finished pages — text, images and conditional badges all bound to data, batch-rendered by citcat-cli. Shown as exported output, not the raw file: a raw .citcat would display literal {{placeholder}} text in a browser, since only the export path resolves bindings.

Product Showcase — SQLite

Exported HTML5

The identical template, run against a SQLite table instead of a CSV — proof the data layer is a swappable connector, not a hardcoded CSV reader.
