# Interactive Training Example

Demonstrates CitCat's interactivity features for e-learning.

## What it demonstrates

- **Quiz with feedback** — three answer buttons that set a result text to different responses
- **Wait points** — scene pauses until the learner clicks to continue
- **Sequential reveals** — PPE items appear one by one using appear_at_ms
- **Multi-scene navigation** — buttons to progress through the training
- **Completion screen** — animated confetti effect with spinning coloured rects

## How to use

1. Open `safety-training.citcat` in CitCat
2. Press Play or export to HTML5
3. Navigate through the training by clicking buttons
4. Answer the quiz on Scene 3
5. See the completion screen
