# Company Presentation Example

Demonstrates CitCat as an animated presentation tool (the PowerPoint killer use case).

## What it demonstrates

- **Wait-for-click navigation** — each slide waits for a click before advancing
- **Staggered reveals** — elements appear one by one using appear_at_ms
- **Scene transitions** — Crossfade, SlideLeft between slides
- **Background gradients** — different gradient per slide for visual variety
- **Scale-up effects** — cards and numbers animate into view
- **Loop navigation** — final slide has a "Start Over" button back to slide 1

## How to use

1. Open `company-intro.citcat` in CitCat
2. Export as HTML5 (single file, autoplay)
3. Open in a browser — click anywhere to advance through slides
4. Or export as MP4 for a video version (each slide plays for its duration)
